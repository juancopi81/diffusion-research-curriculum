# Photos for the score-loss-floor study page

Drop your handwritten pages here. The study page
[`../w13_score_loss_floor_study.html`](../w13_score_loss_floor_study.html)
shows each one beside its step. Any of `.webp`, `.jpg`, `.jpeg` or `.png`
works; the page tries them in that order.

| File name (no extension) | Page content |
| --- | --- |
| `step1-a` | First attempt: the cross term and "y = analytical score" |
| `step1-b` | Full expansion with Adam's law; the two surviving terms |
| `step2` | y as the conditional score, then identity (4) |
| `step3-a` | Eve's law on y; the predict-zero loss equals 4 |
| `step3-b` | Var(y given x_t) = Var(x_0 given x_t) / sigma^4 |
| `step4` | Within-blob variance 0.125 and the 2.0 |
| `step6-a` | The sigma^4 unit change and the leftovers |

Your other handwritten scans live in the gitignored `scratch/` folder. This
folder is tracked, so the photos become part of the repository if you commit
them. Move them to `scratch/` instead if you want to keep them private; the page
then shows a placeholder for each missing photo.
