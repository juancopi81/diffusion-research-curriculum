Squeeze.

fX(x) = fU(u) |dudx| = 1 · F′(x)

Every slice holds 5% of the dots. Where the CDF is steep the slice is narrow, so the dots pile high.

In 2D each cell keeps its share of the dots. Density is how much the cell shrank.

The argument in three moves

Lecture 13 · Universality of the Uniform

Rearrange

U ~ Unif(0, 1)  ⇒  F−1(U) ~ F

Every distribution is the same uniform dots sent to new places. For Expo(1) the map is x = −ln(1 − u), and u = 0.7 lands at 1.204, the worked example in the notes. Run the map backwards and F(X) is uniform again.

Lecture 22 · Change of variables

Squeeze

fY(y) = fX(x) |dx/dy|

Moving dots never creates or destroys them, so wherever the map compresses, density has to rise. Apply the rule to X = F−1(U): the uniform density is 1 and du/dx = F′(x), so the density of X is the slope of its CDF. Lecture 13 is Lecture 22 with a flat starting density.

Diffusion · Flow matching

Slowly

d/dt Ft(xt) = 0

Noising adds an independent variable, so each marginal pt is a convolution, the other formula in Lecture 22. The probability flow ODE moves dots so they have exactly those marginals. In one dimension that pins every dot to its quantile: xt = Ft−1(u). The sampler is the inverse CDF method played as a film.

What is exact: the 1D paths are level curves of numerically convolved CDFs, with no ODE solver involved. The 2D finale integrates dx/dt = vt(x) with Heun's method for the interpolant xt = (1 − t)x0 + tε, where the target is a 288 × 288 grid of small Gaussian pixels. That is the path a perfectly trained flow-matching model for this target would follow.

What a real model adds: here the data distribution is known, so nothing is learned. With only samples, a network has to regress vt (or the score, or the noise) from noisy examples. In more than one dimension there are many maps from noise to data. The opening uses the inverse CDF twice, first for x and then for y given x; the finale uses the flow. Along the flow the density obeys the same rule in differential form: d/dt log pt(xt) = −∇·vt(xt).
