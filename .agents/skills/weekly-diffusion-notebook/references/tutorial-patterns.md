# Tutorial Patterns

Use this structure for instructional weekly notebooks:

- Define audience and prerequisites in the first markdown section.
- Keep an outline near the top so readers can skim quickly.
- Pair short markdown explanations with small runnable code cells.
- Include at least one exercise section with a nearby answer scaffold.
- Include one common pitfall and one optional extension.
- Keep solved and unsolved notebooks aligned cell-by-cell where practical.
