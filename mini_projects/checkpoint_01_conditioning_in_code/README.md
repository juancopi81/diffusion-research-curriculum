# Checkpoint 01 - Conditioning in Code

This mini-project turns a biased Monty Hall variant into a concrete conditioning experiment. It derives the conditional probabilities with Bayes' rule and verifies them with Monte Carlo simulation.

## Artifact

- [analysis.md](analysis.md): derivation and interpretation.
- [simulate.py](simulate.py): reusable Monte Carlo simulator.
- [results.ipynb](results.ipynb): theory-vs-simulation plots and convergence check.
- [figures/conditioning_vs_host_bias.png](figures/conditioning_vs_host_bias.png): portfolio figure generated by the notebook.

## Key Result

The unconditional probability that switching wins stays fixed at $2/3$, but the conditional win probability changes with Monty's host bias:

$$
P(W \mid D_2)=\frac{1}{1+p},
\qquad
P(W \mid D_3)=\frac{1}{2-p}.
$$

When Monty strongly prefers opening Door 2, seeing Door 3 opened becomes strong evidence that switching will win.

## What I Learned

Conditioning is not just filtering data after the fact. It changes the probability model by using the observed event as evidence.
